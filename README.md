# SafeSNS

プライバシーと安全を重視した小さなSNSです。すべてのデータはブラウザ内の `localStorage` に保存され、外部サーバーには一切送信されません。

## 機能

- **匿名ハンドル**: パスワード不要で匿名ハンドルネームだけで利用できます。
- **ローカル保存**: 投稿データ、ブロックリストは端末内にのみ保存されます。
- **レート制限**: 連続投稿を5秒間隔で制限します。
- **自動モデレーション**: 不適切な可能性のある表現を含む投稿に警告します。
- **ブロック・通報**: 他のユーザーの投稿を非表示にしたり、通報したりできます。
- **データ消去**: ワンクリックで端末内のすべてのデータを削除できます。
- **依存ゼロ**: 外部スクリプトやトラッキングは使用していません。

## 使い方

1. リポジトリをクローンします。
2. `index.html` をブラウザで開きます。
3. ハンドルネームを入力して入室します。
4. タイムラインに投稿します。

または、任意の静的ホスティングサービスにデプロイしてください。

## セキュリティとプライバシー

- 個人情報やパスワードは収集しません。
- すべての処理はクライアントサイドで完結します。
- データはブラウザのローカルストレージに保存されるため、端末を他者と共有する場合は注意してください。
